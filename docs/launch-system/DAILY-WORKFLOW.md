# TBF Entertainment — Daily Launch Workflow

A simple routine Cecil can run in ~20 minutes a day. Everything lives in the
Airtable base: https://airtable.com/appwnC45fLK2SCgzW

---

## Every morning (10 min)
1. **Launch Tasks → "Today's Tasks" view.** Do the High-priority ones first.
   Move each to In Progress / Done as you go.
2. **Waiting on Amazon Approval view.** The moment it's approved:
   - Books → set **Status = Live**, paste **Amazon Link + ASIN**, set **Launch Date**.
   - Fire the **Launch-day blast** (see LAUNCH-SCRIPTS #1–3).
3. **Content Calendar → today's row.** Post it. Check **Posted ☑**.

## Every afternoon (10 min)
4. **Outreach → "High Priority Outreach" view.** Send 3–5 messages
   (LAUNCH-SCRIPTS #6–9). Check **Message Sent ☑**, set **Next Step**.
5. **Buyers → "Buyers Needing Review" view.** Send 3–5 review requests
   (LAUNCH-SCRIPTS #5). Check **Will Review** when they say yes.
6. **Reviews.** Log any new review: Reviewer, Stars, Review Posted ☑,
   Screenshot Received ☑. Screenshot it for social proof.

## As things happen (all day)
- Someone wants the book → add to **Buyers**, check **Needs Link**, send the link.
- Someone offers to help → add to **Street Team**, set **Status = Invited**.
- New contact/org to reach → add to **Outreach** with a **Category** + **Priority**.
- New file made → add to **Assets** with the **Drive link** + **Status**.

## Weekly (Fridays, 15 min)
- Count: copies moved, reviews posted, outreach sent vs. responded.
- Clear stale follow-ups; bump next week's tasks.
- Plan next week's content (add rows to Content Calendar).

---

## The launch loop (how it all connects)
**Buyers** → ask for **Reviews** → screenshots become **Content** (social proof)
→ content drives more **Buyers**. **Outreach** + **Street Team** widen the top of
the funnel. **Launch Tasks** keep it all moving. **Books** + **Assets** are the
foundation you reuse for every title.

## Simple weekly targets (adjust to you)
- 20+ real people in Buyers
- 5–10 Street Team members
- 25+ Outreach contacts messaged
- 10+ honest reviews in month one
- Post every day from the Content Calendar
