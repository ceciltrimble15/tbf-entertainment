## ⚠️ Distribution rule (read first)

- **Do NOT enroll the eBook in KDP Select without Cecil's (CEO) approval.** KDP Select = 90-day Amazon exclusivity,
  which **blocks** Draft2Digital, Apple Books, Kobo, Google Play, and B&N Nook.
- Going **wide** (D2D/Apple/Kobo/Google/B&N) requires the eBook to stay **non-exclusive**. It's an either/or — pick before publishing the eBook.
- The paperback is unaffected by KDP Select (that's eBook-only) and can go to IngramSpark for bookstore/library reach anytime.
- **Do not upload to any non-Amazon platform yet** — every platform in the Wide Distribution Tracker is flagged
  `CEO Approval Needed` until Cecil green-lights it.

### 4. TikTok / Reels ideas
Film vertical, 15–30s, trending audio. Post 3–5× in launch week.
1. "POV: your uncle wrote a book about the streets and it's actually fire" → flip to cover reveal.
2. Read the first 3 lines out loud, cut to black on the hook line → "link in bio."
3. "Books they don't keep in the library" → stack of urban-fiction faves, end on _Young G's_.
4. Author intro — O.G. Tom Tom on why he wrote it (30s, raw, one take).
5. "Rate this cover 1–10" engagement bait → cover mockup.

**CTA on every video:** "_Young G's vs. Old G's_ — on Amazon now, link in bio."

### 5. Review request script
Send 3–7 days after a buyer receives the book:
> Hey [Name]! Hope you're enjoying _Young G's vs. Old G's_ 🔥 When you get a sec, could you leave an honest review on Amazon? Takes 2 min and helps the book reach more readers. Direct link: {REVIEW LINK}. Screenshot it and send it to me — I'm featuring supporters! 🙏

> **Only ask real buyers.** Amazon removes incentivized/fake reviews and can penalize the listing. Honest reviews only.

### 6. Street Team ask
> I'm putting together a street team for the launch of _Young G's vs. Old G's_ and I want you on it. 🔥 No cost — just love. Here's the kit: cover graphic, 15s video, and the buy link. If you can post to your story/page on launch day and tag @tbfentertainment, that's huge. Down?

Then: add them to **Street Team Activation**, send the asset kit, mark `Asset Sent`, follow up on `Posted?` / `Review Completed?`.

## Website Update Checklist — when the Amazon link goes live

Do this the **same hour** the link goes live so all launch traffic converts. See `LAUNCH_OPS.md` for deploy details.

- [ ] Copy the live Amazon **product URL** (and note the **ASIN**).
- [ ] In `src/App.jsx`, replace the Amazon **search** URL(s) with the real product URL / ASIN and wire the buy button/CTA.
- [ ] (If used) set `FORM_ENDPOINT` / `VITE_FORM_ENDPOINT` so lead capture delivers to `info@tbfentertainment.art`.
- [ ] `npm run build` → verify `dist/`.
- [ ] `npm run build:standalone` (regenerate `standalone.html` — do not hand-edit it).
- [ ] Redeploy (Vercel/Netlify per `vercel.json`).
- [ ] Load the live site; click the buy button → confirm it lands on the Amazon product page.
- [ ] Record the **ASIN** in Airtable **Books** (`ASIN`, `Amazon Link`) and in `ISBN_TRACKING.md`.
- [ ] Update **Books** `Status` → `Live`; set the **Wide Distribution Tracker** Amazon row `Upload Status` → `Live` + paste `Retail Link`.
- [ ] Set the Amazon link in the **Launch Promotion Tracker** launch-day rows and flip them `Ready` → `Scheduled`/`Posted`.
- [ ] Update Instagram **link in bio** and any Linktree.
